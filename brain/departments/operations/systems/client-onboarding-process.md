# Sample — Client Onboarding Process

What should happen between a client signing and their campaign actually
going live.

**Steps (draft):**

1. Contract signed → kickoff call scheduled
2. ICP and offer details collected from the client
3. Outbound assets set up (email/SMS sending accounts, [[trello]] board)
4. First campaign live
5. Weekly check-in cadence starts
